# Kairos (weather) - sensor monitoring
This package will monitor sensors for temperature, humdidty, CO₂, ...  
It will also utilize ADCs & DACs to monitor devices like hall effect  
sensors to measure current and determine if a boiler or radiator pump is on.  

It will report via initial state, and Prometheus, as well as OLED displays.  

It is a refactoring and replacement for both GreenHouse and MushroomHouse packages.
